NOTE ON TRIANGULAR PRISM / WEDGE
--------------------------------
Your existing code uses Entity.polygon extrusion (weapon triangle). That produces vertical sidewalls.
The recipe engine currently treats "triangularPrism" as a "box-like body" for layout purposes.
If you want a true triangular prism silhouette later, implement it using Cesium.Primitive + custom Geometry.
For now, you can map triangularPrism -> box in the renderer without breaking the mapping table.

tailored to your globeAdapter conventions (heightReference, label styling, safety net cleanup).
